# @arkenforge/arken-auth-darwin-arm64

Prebuilt native binary for `@arkenforge/arken-auth` on macOS ARM64.

This package is installed automatically as an optional dependency — you do not need to install it directly.

```bash
npm install @arkenforge/arken-auth
```

See [@arkenforge/arken-auth](https://www.npmjs.com/package/@arkenforge/arken-auth) for documentation.
